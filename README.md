# AgriTrade Hub 🌾

An automated, event-driven B2B agricultural trading marketplace engineered to streamline contract bidding between network producers (farmers) and bulk commercial buyers.

---

## 🚀 Core Features & Platform "Smartness"

* **Automated Market Baseline Guardrails:** Automatically evaluates buyer contract proposals against real-time crop market baselines, flagging high-visibility `Below Market Val` (lowball) warnings dynamically.
* **Idempotent Self-Seeding Database:** Automatically provisions, scales, and seeds essential schema configurations and pricing baselines securely on launch without data duplication crashes.
* **Auto-Provisioning Profile Shells:** Intercepts fresh user authentication loops to seed missing profile configurations on the fly, eliminating structural database crashes.
* **Comprehensive Administrative Control Room:** A unified parameters dashboard allowing system admins to adjust global transaction fees, lowball deviation margins, and track structural changes instantly via an immutable **System Audit Log**.
* **Privacy-Safeguarded Catalog:** Teases broad logistical hubs and crop specs to public browsers while withholding direct contact signatures until transaction agreements are legally struck.

---

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS, Lucide Icons, React Router
* **Backend:** Node.js, Express, JSON Web Tokens (JWT), Bcrypt
* **Database:** MySQL (Relational Layer with transaction connection pooling)
